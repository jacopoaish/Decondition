# Decondition

Un'app per interrompere le vecchie abitudini e costruirne di nuove, basata su metodi validati dalla ricerca: piani se-allora, WOOP, urge surfing, prevenzione delle ricadute, risposta alternativa e misura settimanale dell'automaticità (SRBAI).

Funziona offline su iPhone e Android ed è in italiano e inglese. I dati restano sul telefono.

**Installazione:** apri il sito in Safari (iPhone) → Condividi → "Aggiungi alla schermata Home", oppure in Chrome (Android) → ⋮ → "Installa app".
